先分清：PIN 与 Passkey（通行密钥）。
PIN 用来解锁设备或验证器；Passkey 才是用于登录 Amazon 的凭据。使用 DIYVM 时，解锁的是插件保险库，输入的是插件主密码，不是 Windows PIN。

01

从 Chrome 商店添加插件

这一步在电脑上的 Google Chrome 中完成。

  1. 打开电脑上的 Google Chrome（谷歌浏览器）。如果桌面没有图标，可从 Windows 开始菜单搜索“Chrome”并打开；不要在手机浏览器中操作。
  2. 点击下方“打开插件商店页面”按钮，直接进入 DIYVM Local Passkey 的 Chrome 商店详情页，无需搜索。如果链接在其他浏览器中打开，请复制链接到 Chrome 地址栏再打开。
  3. 点击详情页的“添加至 Chrome”（Add to Chrome）。阅读 Chrome 弹出的权限说明，再点击“添加扩展程序”（Add extension）。
  4. 等待安装完成。如果按钮变成“从 Chrome 中移除”，说明已经安装；不要再点移除。首次安装可能自动打开欢迎引导页，先保留该页面。
打开插件商店页面 ↗
版本提示：本教程的首次引导、8 字符主密码和通用 Passkey 设置以 1.2.7 为准。若安装后界面不同，可在 chrome://extensions → DIYVM Local Passkey →“详情”检查版本。商店仍提供旧版时，请以该版本实际界面为准，等待新版发布后再按本文的新功能步骤操作，无需反复卸载重装。
这里不需要开发者模式。 正式商店版不用下载 ZIP、运行 EXE，也不用“加载已解压的扩展程序”。如果商店打不开，先解决商店访问问题；不要从不明网站下载同名插件。
02

找到插件，固定到 Chrome 工具栏

安装完成后，图标不一定立即出现在地址栏旁边。

  1. 看 Chrome 窗口右上角、地址栏右边，点击拼图形状的“扩展程序”按钮。它不是最右侧的三个点菜单。
  2. 在展开的列表中找到 DIYVM Local Passkey，点击这一行右侧的图钉 / 固定按钮。
  3. 地址栏右边出现 DIYVM 插件图标后，点击该图标，即可打开插件弹窗。
  4. 也可以不固定：每次点击拼图按钮，再点击列表里的 DIYVM Local Passkey 名称打开。
列表里没有插件？ 在地址栏输入 chrome://extensions 并按回车，检查 DIYVM Local Passkey 是否已安装、开关是否打开。还要确认当前使用的是安装它时的同一个 Chrome 用户配置。切换了浏览器头像，插件可能不在当前配置中。
03

完成首次设置：授权、创建保险库

欢迎页负责开启网站权限；插件弹窗负责创建和解锁保险库。

A. 在欢迎页启用通用 Passkey

  1. 回到安装后自动打开的“欢迎使用 DIYVM Local Passkey”页面，点击“启用通用 Passkey”。
  2. 阅读 Chrome 显示的网站访问权限说明并确认。此项允许插件在 HTTPS 网站响应通行密钥请求。
  3. 看到“通用 Passkey 已启用”提示后，点击“完成并关闭”；后续操作继续在工具栏的插件弹窗中完成。

B. 点击工具栏图标，创建本地保险库

  1. 按步骤 02 打开插件弹窗，在“主密码”输入框中设置一个至少 8 个字符的主密码，点击“创建 Vault”。
  2. 主密码是你为 DIYVM 新设置的保险库密码，不是 Amazon 密码，也不是 Windows PIN。主密码无法找回，请自行妥善保管。
  3. 如果按钮显示“解锁”，说明已有保险库，输入原主密码即可，不要按新用户方式重新设置。
  4. 可选：在可信的个人电脑上，可以勾选“信任此设备，重启 Chrome 后自动解锁”，并阅读随后出现的风险确认。共享电脑不要勾选；启用后，能使用同一 Chrome 用户配置的人也可能访问保险库。

C. 检查设置，再打开 Amazon

  1. 解锁后点击插件中的“设置”标签，检查“在所有 HTTPS 网站启用本地 Passkey”是否已勾选。
  2. 如果欢迎页被关闭或当时点了跳过，直接在这里勾选该项，阅读并确认 Chrome 的网站权限提示即可。
  3. 此教程不需要设置“指定网站自动填充”，也不需要配置 OSS 云备份；这些是其他功能，与创建 Passkey 不是同一个开关。
  4. 回到 Amazon 页面，刷新页面后再开始添加通行密钥。已有 Amazon 标签页尤其需要刷新。
准备完成的标志：插件已解锁、通用 Passkey 已启用、Amazon 页面已刷新。接下来才进入 Amazon 账户设置。
04

打开 Amazon「登录与安全」

先用你现有的方式登录，需要时完成账户验证。

在 Amazon 顶部找到 Account & Lists（账户与列表），进入 Your Account（您的账户），选择 Login & security（登录与安全）。

卖家账户：进入 Seller Central 的登录设置（Login & Settings），寻找 Create Passkey / Set up。具体名称以账户实际显示为准。查看官方说明 ↗
05

点击设置，创建本地通行密钥

先在 Amazon 发起，再在 DIYVM 确认。

找到 Passkey（通行密钥），点击 Set up（设置）。如果随后出现介绍页，再按页面提示点击设置。已有通行密钥的账户可能显示管理或添加入口。

DIYVM 弹出“创建本地通行密钥”窗口后，检查调用页面属于你正在使用的 Amazon 站点，再点击“使用本地通行密钥”。等待 Amazon 返回设置成功。

出现 Windows PIN 或扫码窗口？ 这是 Chrome / 系统验证器流程。想把密钥保存在 DIYVM，请先检查步骤 03 的解锁状态与网站权限，刷新 Amazon 后重新发起。
06

确认保存，再试一次登录

Amazon 设置成功 + 插件出现条目，两个地方都确认。

  1. 等 Amazon 显示通行密钥设置成功或已添加，再打开插件的“通行密钥”列表，检查对应网站与账户。
  2. 保持插件保险库解锁，退出 Amazon 后重新登录，按页面提示使用通行密钥。
  3. 若登录页提供 DIYVM 账户候选，选择正确账户；也可通过页面的通行密钥登录入口继续。候选列表是否出现取决于网站的登录方式。
  4. 在 DIYVM 确认窗口点击“使用本地通行密钥”，完成登录。Amazon 若继续要求验证码，按页面提示完成。
设置完成后：在插件“安全”页导出一份加密备份。更换电脑或重装插件时，需要备份与对应主密码来恢复本地保险库。

另一种保存方式

如果你想用的是 Windows PIN

你可以将通行密钥保存在 Windows Hello。它与 DIYVM 是两条不同的保存路径，不会因为设置其中一个就自动复制到另一个。

本文主线

保存在 DIYVM

解锁插件保险库，在 DIYVM 确认窗口选择“使用本地通行密钥”。使用插件主密码管理本地保险库。

系统验证器

保存在 Windows Hello

在 DIYVM 确认窗口选择“改用 Chrome / 系统”，再从浏览器提供的保存位置中选择 Windows 设备或 Windows Hello。

  1. 如果尚未配置 Windows Hello，在 Windows 设置 → 账户 → 登录选项中设置 PIN。
  2. 按步骤 04 和 05 在 Amazon 发起通行密钥设置，然后选择 Chrome / 系统流程。
  3. 明确选择 Windows Hello / Windows 设备作为保存位置。看到 Windows 安全窗口时，输入这台电脑的 Windows Hello PIN，或按提示使用指纹、人脸。

遇到问题时

常见问题

安装好了，为什么 Chrome 右上角找不到图标？

新安装的插件可能收在拼图形状的“扩展程序”菜单里。点击拼图，找到 DIYVM Local Passkey，点击右侧图钉即可固定；直接点击插件名称也可以打开。若列表中也没有，输入 chrome://extensions 检查是否安装并启用，以及是否用了另一个 Chrome 用户配置。

安装后欢迎页关掉了，还能继续吗？

可以。点击工具栏插件图标，创建或解锁保险库后进入“设置”，勾选“在所有 HTTPS 网站启用本地 Passkey”并确认 Chrome 权限。无需卸载重装，也无需重新打开欢迎页。

找不到 Passkey / Set up 入口？

确认已经登录正确账户，并进入“登录与安全”。不同国家站点、账户类型与界面版本可能显示不同入口；卖家账户可在 Seller Central 的“Login & Settings”中寻找“Create Passkey / Set up”。仍未显示时，请参考该站点 Amazon 帮助。

点击设置后，DIYVM 没有弹出来？

检查插件是否启用、保险库是否解锁，以及通用 Passkey 和 Chrome 网站访问权限是否已开启。刷新 Amazon 页面后重试。如果网站请求不受支持，插件可能交给 Chrome / 系统验证器处理。

美国站创建后，其他 Amazon 国家站也能用吗？

不要默认通用。不同 Amazon 国家站可能要求分别设置通行密钥，请在目标站点检查“登录与安全”。插件支持通用 HTTPS 网站，并不代表一枚密钥可以跨任意域名使用。Amazon 官方帮助 ↗

已经启用通行密钥，为什么还要验证码？

通行密钥不是关闭两步验证的开关。Amazon 仍可能根据账户设置和本次登录情况要求额外验证，按页面提示操作即可。

重启浏览器后可以不再输入插件主密码吗？

可以在 DIYVM 解锁页或设置中开启“信任此设备，重启 Chrome 后自动解锁”。这会让能使用同一 Chrome 用户配置的人也能访问保险库，请只在可信的个人设备上使用；主密码仍应保留，用于备份恢复等操作。

忘记主密码或重装插件后怎么办？

新环境恢复 DIYVM 本地保险库需要加密备份及对应主密码，扩展没有主密码找回服务。没有可用备份时，可通过 Amazon 提供的密码或账户恢复方式登录，再重新添加通行密钥。
