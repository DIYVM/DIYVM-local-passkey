## 商品详情

### 名称

DIYVM Local Passkey

### 简短说明

在 Chrome 本地加密保存密码与通行密钥，可选在所有 HTTPS 网站启用，并备份到自有 OSS。

### 详细说明

DIYVM Local Passkey 是一款不依赖 DIYVM 账户或开发者服务器的本地优先密码与通行
密钥管理器。

它将密码和通行密钥保存在同一个加密保险库中。用户可以添加、编辑、搜索、
收藏、标记和恢复凭据，使用密码生成器，并在本地检查弱密码、重复密码和长期未更新的
密码。保险库支持自动锁定、修改主密码、加密备份、备份验证和完整恢复。

在普通 HTTP/HTTPS 网站上，用户点击扩展后可以读取或填充当前登录表单；扩展不会自动
提交。HTTP 凭据严格绑定 HTTP Origin，不与 HTTPS 互通，每次填充前都会显示未加密
连接警告。
点击式填充不需要长期访问网站。只有当用户明确为某个精确 HTTPS 网站开启持续自动
填充时，Chrome 才会显示该网站的权限提示，而且可以随时撤销。
填充会优先识别当前登录弹窗，并支持同源 iframe、开放式 Shadow DOM 和先账号后密码
的分步登录；跨域 iframe 不会接收其他 Origin 的凭据。

扩展不再预授权或特殊处理 Amazon 等特定网站。用户可以主动开启“通用 Passkey”；
只有确认后才申请全部 HTTPS 网站的
可选权限。每次创建或使用本地通行密钥都会显示独立确认窗口，也可以改用 Chrome 或
系统验证器。Vault 不可用、没有本地凭据或网站参数不受支持时自动回退原生验证器。
Conditional UI 和跨域 iframe 不由扩展接管。关闭全站开关会移除动态脚本并撤销全站
权限。

密码、通行密钥私钥和操作日志均使用 AES-256-GCM 加密后保存到浏览器本地。新保险库
使用 Argon2id 保护随机 Vault Key。扩展不包含广告、分析、遥测或 DIYVM 云同步服务。
用户可以选择把完整加密备份手动上传到自己的阿里云 OSS；该功能默认关闭，不经过
DIYVM 服务器，AccessKey Secret 也作为加密记录保存在本地保险库中。

重要安全提示：密码填入网页后，该网页自身的脚本可能读取输入框内容。请只在可信且
域名正确的网站填充。软件通行密钥的硬件隔离强度也低于 TPM、Secure Enclave 或
独立安全密钥。

## 隐私权

### 单一用途

本扩展的单一用途是在用户的 Chrome 浏览器本地加密保存、管理并使用网站密码和
通行密钥。所有权限都用于凭据保险库、当前页面登录填充、用户逐站点启用的自动填充、
用户主动授权的通用通行密钥操作、自动锁定，以及用户明确启用的本地或
自有 OSS 加密备份。

### `storage` 权限理由

用于保存不含明文密码的扩展设置，并在浏览器会话内临时保存解锁状态。密码、通行密钥
私钥和操作日志均以 AES-256-GCM 加密后保存在本扩展的本地 IndexedDB 中。

### `activeTab` 权限理由

用户点击扩展后，临时访问当前标签页，以识别当前 HTTP/HTTPS Origin，并执行一次性
的登录表单读取或密码填充。HTTP 填充需要逐次确认风险。访问随页面导航或标签页关闭
而结束。

### `scripting` 权限理由

用于在用户明确点击“读取当前表单”或“填充当前页面”时执行一次性脚本；也用于在用户
单独授权的精确 HTTPS Origin 注册或移除自动填充脚本。用户开启全站 Passkey 后，
还用于在 HTTPS 顶层页面加载初期注册 WebAuthn 桥接；桥接只处理网页主动发起的
`navigator.credentials.create/get` 参数，不扫描页面内容。密码脚本仅查找登录输入框，
不点击按钮或提交表单。

### `alarms` 权限理由

用于在用户选择的 5 分钟至 24 小时无活动期限到达时锁定保险库并清除会话密钥。

### 必需主机权限理由

无。扩展安装时不会获得任何网站访问权限，也不会向任何网站静态注入脚本。

### 可选 `https://*/*` 主机权限理由

扩展不会在安装时获得任意网站访问权。该声明有三种用户可见用途：

1. 用户主动开启“通用 Passkey”后，一次申请全部 HTTPS 权限；
2. 用户只为某个 HTTPS 网站开启持续自动填充时，申请该精确 Origin；
3. 用户提交自己的阿里云 OSS 配置时，申请精确 Bucket 主机。

全站 Passkey 默认关闭；用户拒绝权限时保持 Chrome/系统 WebAuthn，关闭开关会撤销
全站权限。默认点击式密码填充使用 `activeTab`，不依赖此可选权限。

### 是否使用远程代码

选择：`否，我未使用远程代码`

理由：全部 JavaScript 和 Argon2id 实现都已打包在扩展内。扩展不从网络下载或执行
JavaScript、Wasm、动态模块、配置脚本，也不使用 `eval` 或远程 CDN。

## 数据使用选项

建议勾选：

- `个人身份信息`：登录名可能是电子邮箱地址；该信息仅作为本地凭据字段处理。
- `身份验证信息`：用户名、密码、通行密钥材料和 WebAuthn 请求/响应。
- `网站内容`：用户明确读取登录表单时处理页面标题和表单内容。
- `网络记录`：建议勾选。扩展会为精确 Origin 匹配凭据，并处理用户正在交互的网站
  域名/URL；Google 的用户数据说明将此类信息归入浏览活动/网络记录。

不要勾选：

- 健康信息
- 财务和付款信息
- 个人通讯
- 位置
- 用户活动（点击、滚动、鼠标或键盘行为记录）

下方三项承诺全部勾选：

- 我不会出于已获批准的用途之外的用途向第三方出售或传输用户数据。
- 我不会为了与产品单一用途无关的目的而使用或传输用户数据。
- 我不会为了确定信用度或实现贷款而使用或传输用户数据。

### 数据使用补充说明

扩展不向开发者服务器发送保险库。向当前网站提供用户选定的密码或通行密钥结果，是
完成用户要求的登录操作所必需的。用户明确启用 OSS 后，扩展仅把完整加密备份发送到
用户填写并授权的阿里云 OSS Bucket；DIYVM 不接收、不持有也不能读取该备份。

## 测试说明

可直接提交以下内容：

1. 安装扩展并点击工具栏中的 DIYVM Local Passkey。
2. 首次使用时输入至少 8 个字符的主密码并创建本地保险库。
3. 打开任意 HTTPS 登录页，在表单中输入测试用户名和密码，但不要提交。也可以在 HTTP
   测试页验证密码只能在风险确认后保存和手动填充，且不能开启持续自动填充。
4. 回到扩展的“当前页面”，点击“读取当前表单”，保存后点击“填充当前页面”。
5. 点击式填充不需要网站长期权限；请确认扩展不会自动提交表单。
6. 如需测试持续自动填充，在该测试网站上开启“允许此网站自动填充”，接受 Chrome
   对当前 Origin 的权限提示，刷新页面后验证；测试后可以撤销。
7. 在“设置”中开启“通用 Passkey”，阅读披露并接受 Chrome
   的全站可选权限提示，然后刷新 `https://webauthn.io/`。测试创建与登录，并分别
   选择“使用本地通行密钥”“改用 Chrome / 系统”和“取消本次操作”。关闭开关后确认
   权限与动态脚本已撤销。
8. “安全”页可测试密码生成、风险统计、回收站、加密备份验证与恢复。
9. 可选 OSS 测试位于“设置”：填写测试人员自己的阿里云 OSS 公网 Endpoint、
    Region、Bucket、对象路径和最小权限 RAM AccessKey，勾选披露后点击“保存并测试
    连接”；随后可上传、检查、恢复或断开。该功能不是审核其他本地功能的前置条件。

除测试人员主动启用的用户自有 OSS 外，所有数据都保存在测试浏览器配置文件本地，
不需要 DIYVM 账户或开发者服务器。

## 审核备注

`1.2.1` 延续通用 HTTPS Passkey 模式，并将新主密码要求统一为至少 8 个字符，新增
2 小时、8 小时和 24 小时自动锁定选项。解锁密钥仍仅保存在 Chrome 会话存储中。
点击式密码保存和填充支持 HTTP/HTTPS，HTTP 操作
需要风险确认且不能持续自动填充。宽泛的 `optional_host_permissions` 也用于用户主动
开启的全站 Passkey 模式；它默认关闭，不是安装时权限。拒绝该权限不会妨碍 Chrome/
系统验证器、保险库、密码管理、点击式填充、密码检查和本地备份测试。
